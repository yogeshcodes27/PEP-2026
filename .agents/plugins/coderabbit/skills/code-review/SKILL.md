# CodeRabbit Code Review

AI-powered code review using CodeRabbit. Detects bugs, security risks, performance issues, and code smells across changed files.

## Capabilities
- Finds bugs, security issues, and quality risks in changed code.
- Categorizes findings by severity: Critical, Major, Minor, Info.
- Reviews staged, unstaged, or specific directory changes.
- Uses agent-readable review output and targeted fix guidance.

## Triggering Review
When user asks to:
- "Review my code" / "Review changes"
- "Run code review" / "Check quality"
- "Find bugs or security issues"
- "CodeRabbit review"
